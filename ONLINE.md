# Онлайн-режим на двоих (Serverless WebRTC)

Игра остаётся бесплатной и без своих серверов: два браузера соединяются напрямую (WebRTC), а приглашение и ответ игроки передают друг другу вручную. Экран — «ОНЛАЙН ЛОББИ» на рабочем столе NEXA/OS (кнопка ONLINE LOBBY).

## Как играть вдвоём

1. **Хост** (игрок 1): ONLINE LOBBY → вкладка CONNECTION → «CREATE INVITATION». Появится ссылка вида `<адрес игры>?join=NX1O.…` — скопируй и отправь другу.
2. **Друг** (игрок 2): открывает ссылку — лобби откроется само, код подхватится из адреса и ответ создастся автоматически. Если браузер/iframe не отдаёт адрес — вставь ссылку или чистый код в поле «PASTE THE HOST'S LINK OR CODE» и нажми «CREATE ANSWER».
3. Друг копирует **код ответа** (`NX1A.…`) и присылает хосту.
4. Хост вставляет его в поле «PASTE YOUR FRIEND'S ANSWER CODE» и жмёт «CONNECT». Делайте обмен без долгих пауз (около минуты) — пока вы копируете коды, ICE-проверки уже идут.
5. В лобби: хост выбирает режим (серая кнопка «MISSION / SANDBOX WITH A FRIEND»: песочница или миссия 1–47; миссия 48 недоступна), друг жмёт «READY», хост — жёлтую «PLAY». Оба запускают один режим (id и seed от хоста).

Хостом может быть любое устройство. Хост = игрок 1, друг = игрок 2. Без друга «PLAY» запускает обычную одиночную игру.

## Что синхронизируется

- Позиция, поворот, присед, оружие в руках, ADS, жизни, смерть/возрождение напарника (~15 Гц по каналу `act`, в покое 2 Гц, квантование до 2 см).
- Выстрелы (трассеры, вспышка, звуки игры, искры), взрывы, эмоции (танцы), ник над головой.
- Текстовый чат (≤ 200 символов, санитайзинг, антифлуд) и голос (микрофон через WebRTC; `M` — вкл/выкл микрофон, `Enter` — чат в игре).
- **CO-OP SANDBOX**: враги общие. Хост — авторитет: ИИ, волны, цель (ближайший игрок), снапшоты ~10 Гц; у друга враги — «куклы», попадания друг шлёт хосту, урон по другу присылает хост.
- Профиль: ник, цвет, уровень и статистика (миссии, убийства, смерти, меткость, время, онлайн-матчи, сообщения) хранятся локально; собеседнику уходят только ник, цвет и уровень.

## Ограничения (честно)

- **Сюжетные миссии**: каждое устройство считает врагов и ход сюжета само (общий seed лишь выравнивает декор). Синхронны напарник, выстрелы, эмоции, чат, голос; но враги, убитые одним, могут жить у другого, а завершение миссии у каждого своё.
- Нет TURN-сервера: при **симметричном NAT** / жёстком файрволе прямое соединение невозможно. Помогает другая сеть, VPN или раздача с телефона. Используются только публичные STUN Google (`stun:stun.l.google.com:19302`, `stun:stun1.l.google.com:19302`).
- Если оба в одной сети Wi-Fi, а соединение не идёт — включите «SAME WI-FI / LAN MODE» (в код попадут локальные кандидаты).
- Страховка 2.5 с: если сбор ICE затянулся, код выдаётся из того, что успели собрать.
- Код приглашения — закодированный (deflate + Base64url), **не секретный**: внутри данные соединения. Отправляйте его только другу.

## Приватность IP

IP нигде не показывается в интерфейсе, чате и журнале (адреса вырезаются), по каналам не отправляется. В код попадают только srflx/relay-кандидаты (host/mDNS — только если ничего другого нет или включён LAN-режим). Но при прямом P2P-соединении браузер собеседника технически видит ваш сетевой адрес — это свойство WebRTC, без TURN-сервера скрыть его полностью нельзя; VPN скрывает реальный адрес.

## itch.io (iframe)

- Ссылка `?join=` читается из `location.search`/`#join=` в `try/catch`; если iframe не отдаёт адрес, остаётся ручная вставка в поле.
- Для голосового чата рамка игры должна иметь `allow="microphone"` (настройка встраивания на странице игры). Без него браузер откажет в микрофоне — игра покажет понятное сообщение, текстовый чат работает.
- Ссылка на официальный Telegram-канал: https://t.me/nexaindustries (вкладка TELEGRAM, карточка и чат).

## Как проверить самому вдвоём

**На одном ПК (два окна).** Откройте игру в двух окнах: обычное + окно инкогнито (или второй профиль браузера) — у них раздельное хранилище, поэтому это «два игрока». Адрес один и тот же (`http://127.0.0.1:8765` или файл на хостинге).
1. Окно 1: ONLINE LOBBY → CONNECTION → CREATE INVITATION → COPY LINK.
2. Окно 2: вставьте ссылку в адресную строку (или в поле FRIEND) → код ответа создастся сам → COPY CODE.
3. Окно 1: вставьте код ответа → CONNECT. Статус станет CONNECTED, у друга появится платформа и ник.
4. Окно 2: READY, окно 1: PLAY. В обоих окнах нажмите ENTER на экране загрузки — напарник появится в мире.
5. Проверьте: движение/выстрелы видны в другом окне, чат (Enter в игре), волны врагов в песочнице общие, эмоция (зажатая B) видна напарнику.
Один браузер в двух вкладках тоже работает, но неактивная вкладка получает меньше кадров — для проверки лучше два окна рядом. Микрофон на одном ПК даст эхо: отключайте динамики или используйте наушники.

**Через интернет с другом.** Сделайте то же самое, передавая ссылку и код ответа любым мессенджером. Не затягивайте обмен кодами (около минуты). Для голоса оба разрешают микрофон в браузере.

**Типичные ошибки.**
- «No invitation code found / code is damaged» — код скопирован не целиком; копируйте кнопкой COPY.
- «This answer belongs to another invitation» — хост создал новое приглашение, а друг ответил на старое; нужен ответ именно на последнюю ссылку.
- «Could not connect…» — строгий NAT/файрвол (нет TURN). Другая сеть, VPN или раздача с телефона; в одной сети Wi-Fi — режим SAME WI-FI / LAN.
- «No public address found» — STUN заблокирован; код сработает только внутри одной сети.
- «Microphone access denied» — разрешите микрофон в адресной строке; на itch.io нужен `allow="microphone"`.
- Друг не слышен — браузеру нужен клик по странице (автоплей), см. подсказку «Click anywhere…».
- Версии игры разные (кэш) — обновите страницу у обоих (Ctrl+F5).

## Синхронизация врагов в сюжетных миссиях 1–47

Не сделана намеренно: сценарии миссий — асинхронные скрипты, которые сами создают врагов и ждут их смерти (`await`), и привязаны к позиции каждого игрока. Подмена врагов «куклами» хоста ломала бы ход сценария у друга (триггеры, чекпойнты, катсцены). Безопасный вариант (общие враги хоста) реализован только для CO-OP SANDBOX.
