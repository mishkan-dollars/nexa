# VOICE_LINES_EN — English voice-over script for ElevenLabs

120 lines, about 7124 characters (≈ 7124 credits on the standard models; check your plan). Generated by `node tools/extract-voice.js`.

Workflow: for each character create or pick ONE voice, generate all of that character's lines with the same settings, download as mp3 and save as `assets/voice/<code>.mp3` (code is in the first column). The text is already converted from ALL CAPS to normal sentence case, because ElevenLabs reads capitals too loudly.

Voice names are ElevenLabs premade voices; the library changes over time, so every character also has a Voice Design prompt (Voices → Add a new voice → Voice Design) that you can paste instead.
