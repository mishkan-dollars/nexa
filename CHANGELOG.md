# HIGH / LOW — ИСПРАВЛЕНИЯ

## КРИТИЧЕСКИЕ ИСПРАВЛЕНИЯ

### 1. ✅ МУЗЫКА: PICK → GAME
**Проблема:** pick.m4a продолжал играть во время GAME, game.mp3 не запускался.

**Исправлено:**
- `pick.m4a` теперь имеет `loop: false` вместо `loop: true`
- При переходе в GAME музыка корректно переключается:
  - `stopMusic()` останавливает pick.m4a
  - Через 100ms запускается `game.mp3` в loop
- Последовательность: `menu.mp3` → `pick.m4a` → `game.mp3` → `menu.mp3`

### 2. ✅ HARDDRIVE ЗВУК
**Проблема:** harddrive.mp3 останавливался при переходах.

**Исправлено:**
- `harddrive.mp3` работает независимо от музыки
- Запускается при boot и продолжает играть во всех состояниях
- Громкость 12%, loop: true
- Не останавливается при переключении музыки

### 3. ✅ ВЫБОР ЧИСЛА
**Проблема:** Невозможно было выбрать число, input не работал.

**Исправлено:**
- Input имеет `autofocus` для автоматического фокуса
- Добавлен hover эффект на input
- Кнопка теперь называется "LOCK NUMBER" вместо "LOCK"
- Добавлена проверка на пустое значение
- Защита от двойного нажатия через `pickSubmitting` флаг
- Визуальный feedback при disabled состоянии

### 4. ✅ АВТОВЫБОР ЧИСЛА
**Проблема:** Если игрок не выбрал число за 15 секунд, игра зависала.

**Исправлено:**
- При истечении таймера автоматически выбирается случайное число
- Показывается экран AUTO-SELECTION с выбранным числом
- Анимация: "TIME EXPIRED" + "SELECTED: XX"
- Задержка 2400ms перед переходом в GAME
- Звук notification при автовыборе

### 5. ✅ ТАЙМЕР 15 СЕКУНД
**Проблема:** Таймер не всегда корректно работал.

**Исправлено:**
- Таймер обновляется каждые 100ms
- При 0 секунд автоматически вызывается `finishPicking()`
- Критическое состояние при ≤5 секунд
- Интенсивные эффекты при ≤3 секунд
- Таймер останавливается после выбора
